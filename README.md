# GLP-1 RA in T2D — Trial Watch

Tracking repository for the endocrinology group's quarterly pipeline review on the theme **GLP-1 receptor agonists in type 2 diabetes**.

## Purpose

Capture the late-stage ( Phase 3 ) recruiting landscape of GLP-1 receptor agonist studies in adults with type 2 diabetes directly on GitHub so the team can find it without digging through notes.

## Contents

- One tracking issue per selected Phase 3 trial (NCT ID in title; sponsor, phase, planned enrollment, and primary completion date in the body).
- A parent summary issue with aggregate breakdowns of the same search (by phase and by sponsor class).
